# SlotMem 身份记忆融合验证实验记录（2026-08-26）

## 摘要

本试验研究 SlotMem 的身份记忆残差在人物消失后重现场景中，究竟能够为冻结的去噪模型补充有效信息，还是会因为注入强度过大而干扰当前视频表征。试验没有训练新模块，也没有改变模型权重、记忆载荷或查询路径，而是在现有 teacher-forced identity probe 上比较无记忆、正确记忆和匹配错误记忆，并对两个候选 timestep–layer cell 进行受控的注入强度扫描。结果表明，身份记忆的作用具有明显的 timestep 和层位置依赖性。在 timestep 25 的后层（layers 11–15），正确记忆相对无记忆产生小幅收益，而错误记忆产生损害，构成当前最明确的 identity-specific supplementation 候选。在 timestep 49 的后层，完整注入有害，而较小强度的注入接近无记忆基线，说明该位置存在幅度过载现象；然而，错误记忆在低强度下优于正确记忆，因此本试验不能把该现象解释为已经得到证实的角色表征竞争。总体而言，结果支持“选择正确的 timestep 和后层位置进行小残差融合”这一研究方向，但效应仍局限于单个事件、单个噪声种子和 teacher-forced latent MSE，尚不能证明解码后的人物身份一致性获得改善。

## 研究问题

此前的 SlotMem identity probe 表明，记忆注入能够改变模型预测，但正确记忆并不总是优于无记忆或错误记忆。仅比较完整注入的最终损失，无法区分两种情况：一种是记忆所提供的方向本身错误；另一种是方向中包含有益信息，但完整强度产生的扰动能量过大，从而掩盖了这一收益。本试验因此提出两个相互关联的问题。第一，正确身份记忆所引起的预测变化是否包含能够修正当前去噪误差的方向分量。第二，如果该方向分量存在，降低内部融合强度能否将其转化为可观测收益，并且这种收益是否依赖于记忆内容，而不只是来自通用的 memory path 扰动。

## 实验设计

试验使用人物重现场景 `person_reappearance_delta8`，冻结 source chunk 0、target chunk 8 和 horizon 8，并复用此前验证过的 prefix、correct payload、matched-wrong donor payload、teacher target、prompt 和参考图像。噪声种子固定为 0，分析 timestep indices 0、25 和 49。基础层组为 layers 0–4、5–10 和 11–15；timestep 25 还保留了全层 0–15 的已有对照。所有计分均基于 conditional velocity prediction，不计算 CFG unconditional 分支，也不进行模型训练或解码视频生成。

基础筛查阶段执行了 25 个 measured arms，包括各 timestep 和层组上的 correct、wrong 与 no-memory 对照，以及用于运行合同校验的 correct repeat 和 zero 条件。随后，V0 阶段直接复用这些预测进行误差向量分解，不增加模型 forward。满足“正确记忆方向项为负、预测最优强度位于 0 与 1 之间、预测收益大于 trigger floor”的 cell 才进入 V1。候选按预测收益排序，并优先选择不同 timestep，最终选择 timestep 49、layers 11–15 和 timestep 25、layers 11–15。每个 cell 分别对 correct 和 wrong memory 执行 α∈{0, 0.25, 0.5, 1} 的 matched sweep，共增加 16 个 measured arms。

本次运行共完成 41 个 measured arms 和 1 个 warm-up arm。原始 DiT 调用由 39 次截断 semantic prepass 和 42 次 conditional DiT 构成，共 81 次，没有 unconditional DiT 调用。运行使用 NVIDIA A100 80GB PCIe、PyTorch 2.7.1+cu128 和 FlashAttention 2，峰值 allocated memory 为 57.41 GB，峰值 reserved memory 为 58.76 GB。S0/S1 用时 1377.45 秒，全部试验用时 2383.25 秒。运行源码提交为 `b9d16cfb7340161e8747ab6599bc714012136a6f`。

## 分析方法

对每个固定 timestep 和层组，以无记忆预测为基线。记无记忆预测为 \(v_0\)，正确或错误记忆预测为 \(v_a\)，teacher-forced target 为 \(y\)，记忆引起的预测变化为 \(\Delta_a=v_a-v_0\)，基线误差为 \(e_0=v_0-y\)。如果在输出空间沿该记忆方向进行线性缩放，\(v_\alpha=v_0+\alpha\Delta_a\)，则相对无记忆的均方误差变化可以精确写为

\[
L(\alpha)-L(0)=\alpha A_a+\alpha^2B_a,
\]

其中

\[
A_a=2\operatorname{mean}(e_0\Delta_a),\qquad
B_a=\operatorname{mean}(\Delta_a^2).
\]

方向项 \(A_a\) 小于零表示记忆变化在无穷小强度下沿着降低原始误差的方向移动；能量项 \(B_a\) 恒为非负数，表示该变化自身引入的二次扰动代价。当 \(B_a>0\) 时，输出空间二次模型给出的诊断性最优强度为 \(\alpha^*=\operatorname{clip}[-A_a/(2B_a),0,1]\)。该 \(\alpha^*\) 只描述无记忆输出与完整记忆输出之间的线性插值，不等价于深层非线性网络内部的真实 scale 最优值，因此必须通过 V1 的实际内部注入进行验证。

试验同时报告两个内容因果分数。\(Q_{presence}=L_{no-memory}-L_{correct}\)，其正值表示正确记忆优于无记忆；\(Q_{content}=L_{wrong}-L_{correct}\)，其正值表示正确记忆优于匹配错误记忆。只有预测发生变化而没有损失改善时，只能说明记忆具有影响力，不能说明它具有任务效用；只有 correct 相对 wrong 的优势才提供内容特异性证据。

## 基础筛查与 V0 结果

基础筛查显示出清晰的时间和层位置差异。timestep 0 的三个层组均具有正的 correct directional term，且正确记忆在所有层组上都劣于无记忆。这说明在当前事件和噪声样本下，初始 timestep 的记忆方向从局部一阶意义上已经与去噪目标不一致，仅通过降低强度不能产生正向的输出空间预测。

在 timestep 25，layers 5–10 的方向项同样为正，完整注入也有害。layers 0–4 和全层 0–15 虽然具有轻微负方向项，但能量项明显更大，预测最优 α 分别只有 0.044 和 0.075，预测收益仅为 1.29×10^-7 和 4.70×10^-7。相比之下，layers 11–15 的方向项为 −2.905×10^-5，能量项为 2.493×10^-5，因此完整正确记忆的净损失变化为 −4.122×10^-6。该 cell 的 \(Q_{presence}=4.113\times10^{-6}\)，\(Q_{content}=1.559\times10^{-5}\)，是基础筛查中唯一同时表现为正确记忆优于无记忆且优于错误记忆的主要候选。

在 timestep 49，三个层组的正确记忆方向项均为负，但完整正确记忆均劣于无记忆。这三个 cell 的共同模式是有益的一阶方向项被更大的二次能量项覆盖。以 layers 11–15 为例，方向项为 −1.933×10^-4，能量项为 3.614×10^-4，两者相加得到约 1.681×10^-4 的净损害；输出空间模型预测最优 α 为 0.267。与此同时，timestep 49 的三个层组均具有正的 \(Q_{content}\)，说明正确记忆虽然不如无记忆，但仍比错误记忆受到的损害更小。该结果区分了“内容具有相对优势”和“记忆具有绝对效用”：前者在 timestep 49 成立，后者在完整注入时不成立。

## V1 强度扫描结果

在 timestep 25、layers 11–15，correct α=0 与 wrong α=0 得到完全相同的 prediction SHA 和损失 0.111084782，说明 matched memory/query path 在残差被置零后没有产生可测的路径混杂。correct α=0.25 的损失下降到 0.111082546，α=0.5 上升到 0.111115493，α=1 再下降到 0.111080669。wrong memory 在三个非零 α 上的损失分别为 0.111100286、0.111101039 和 0.111096255，均高于无记忆基线。由此，correct 在 α=0.25 和 α=1 时不仅优于自身 α=0 基线，也优于同 α 的 wrong memory。自动规则将该 cell 标记为 `supplement_candidate`。这一标签与内容特异性补充的解释一致，但 α 曲线明显不单调；特别是输出空间预测的 \(\alpha^*=0.583\) 并未在内部 α=0.5 时得到验证。这表明内部 scale 改变会经过多层非线性传播，不能把 V0 的输出插值最优值直接用作实际融合超参数。

在 timestep 49、layers 11–15，correct α=0.25、0.5 和 1 的损失分别为 0.521192014、0.521223843 和 0.521360278。相对 α=0 的 0.521192133，α=0.25 只改善 1.19×10^-7，而 α=0.5 和 α=1 均逐渐恶化。这种“极低强度接近或略优于基线、完整强度明显更差”的曲线满足预设的 `representation_competition_candidate` 规则。host drift 和 delta/host ratio 也随 α 增大，因此形式上的机制标签成立。然而，wrong α=0.25 的损失为 0.521187961，比 correct α=0.25 还低 4.05×10^-6；同时 correct α=0.25 的改善仅约为该损失量级上的两个 float32 ULP。因而，这一 cell 最多支持“完整强度存在幅度过载”的判断，不能证明正确角色身份与当前角色表征发生了内容特异性的竞争。

## Host 表征诊断

Host-feature diagnostics 用于判断 memory residual 是否以大幅度替换当前视频 token 表征。timestep 25、layers 11–15、correct α=1 时，平均 effective-delta/host norm ratio 为 0.001772，最大值为 0.002334；注入后 host 与 matched α=0 host 的平均 cosine 为 0.999990。timestep 49、layers 11–15、correct α=1 时，平均 ratio 为 0.008112，最大值为 0.010833，平均 host cosine 仍为 0.999894。正确和错误记忆的 effective delta 在共享 token index 上具有约 0.562 的平均 cosine，说明两者包含较强的共享 memory-path 分量，同时保留足以改变损失排序的内容差异。

这些数值不支持“memory vector 直接覆盖 host representation”的简单模型。更符合观测的描述是：SlotMem 在 host 表征上施加了幅度较小的 residual，但去噪网络对残差的 timestep、层位置和内容方向高度敏感。这里的高 cosine 只证明选中 token 的一阶几何变化较小，不能排除小扰动经过后续层放大，也不能单独证明不存在更抽象的表示竞争。

## 科学解释

本试验最可靠的发现是身份记忆效用具有位置选择性。初始 timestep 的三个层组都不支持注入；timestep 25 的中层方向同样不利；只有 timestep 25 的后层同时满足正确记忆优于无记忆和错误记忆。这说明身份相关 residual 不是一个可以在所有 timestep 和层上均匀施加的静态向量。对于提升人物重现一致性的后续研究，timestep 25、layers 11–15 应当作为首要验证 cell，而不是继续扩大全层注入范围。

第二个发现是 correct 和 wrong memory 同时包含通用作用与内容特异作用。约 0.562 的 delta cosine 表明大量变化方向是共享的，这可以解释为什么错误记忆有时也会改变甚至略微改善整体去噪 MSE。与此同时，timestep 25 后层中 correct 改善而 wrong 恶化，说明共享分量之外确实存在与身份内容相关的方向差异。当前证据支持研究“从共享 memory residual 中提取或保留 identity-specific component”，但尚不能识别具体哪些 video token 构成这一子空间。

第三个发现是幅度调节不能脱离 timestep 和内容进行解释。timestep 49 的 V0 分解清楚显示有益方向项被更大的能量项淹没，但真实低 α 结果缺乏 correct-over-wrong 优势。因此，降低 α 可以缓解损害，却不必然恢复身份特异性。机制上应把“幅度过大”“通用记忆分量”和“身份表征竞争”视为不同假设；本轮数据支持前两者的存在，只为第三者提供了待验证线索。

## 证据边界

本试验是单事件、单 teacher target、单 noise seed 的冻结机制诊断，没有独立重复或统计置信区间。由于 correct repeat 的损失和 prediction SHA 完全一致，确定性运行合同得到了验证，但这不能替代跨噪声种子和跨视频的效应重复。试验的 benefit margin 和 repeat floor 均为零，因此任何严格小于基线的浮点变化都会触发候选规则；这使 timestep 49、α=0.25 的极小改善尤其需要谨慎解释。

本试验使用 teacher-forced conditional latent MSE，它直接测量固定去噪目标上的预测误差，却不是最终人物身份一致性的完整替代指标。试验没有运行 S2 identity-token scoring，也没有执行 decoded validation，因此空的 token score、token group 和 intervention 文件属于预期输出，而不是运行失败。当前结果不能回答哪些 token 明确编码人物身份，也不能证明最终生成视频中的人脸、服装或角色连续性已经改善。

## 结论

在当前人物重现场景中，SlotMem 身份记忆不是普遍有益或普遍有害的。其效用取决于注入 timestep、模型层位置、记忆内容和内部强度。timestep 25、layers 11–15 提供了本轮最明确的 identity-specific supplementation 候选：正确记忆能够小幅降低 teacher-forced loss，而匹配错误记忆使 loss 上升。timestep 49 的结果则表明完整注入的能量代价超过了有益方向，但低强度收益缺乏身份特异性，因此应解释为幅度过载线索，而不是已经证实的角色 representation competition。下一步若以提升人物一致性为目标，应首先对 timestep 25、layers 11–15 的 correct-versus-wrong 效应进行跨 noise seed 重复，在确认效应稳定后再开展解码身份验证和 token-level 身份子空间分析。
