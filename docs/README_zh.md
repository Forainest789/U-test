以及以下入口脚本：

- `train_slotmem_stage1.sh`
- `train_slotmem_stage2.sh`
- `test_slotmem_stage1.sh`

- `bench/run_slotmem_benchmarks_api.sh`

上游参考材料用于维护运行时。这些内容不是 SlotMem 论文代码的主文档。
