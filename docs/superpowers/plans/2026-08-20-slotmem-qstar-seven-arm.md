# SlotMem Q* Seven-Arm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a strict, reproducible seven-run SlotMem evaluation that computes teacher-forced flow-matching Q*, supports a nine-chunk person reappearance event, and optionally validates Q* against full-rollout `C_id` without changing model weights or model math.

**Architecture:** Keep intervention semantics in `utest.content_audit`, add a small Q* arithmetic/report module, and expose one single-timestep teacher-forced prediction path from the existing inference engine. A Q* CLI loads the frozen prefix and future target once, derives one immutable `(x, epsilon, z_tau, tau)` cell per requested scheduler index, evaluates cloned arm payloads, and fails closed on hash/repeat/finite violations. The existing event harness remains the rollout authority and gains only native-diagnostic scheduling plus explicit static/dynamic writer classification.

**Tech Stack:** Python 3, PyTorch, existing DiffSynth/Wan runtime, `argparse`, JSON/JSONL, pytest, Bash.

## Global Constraints

- Do not change checkpoints, attention equations, scheduler equations, CFG, or optimizer/training settings.
- Reuse `utest.content_audit` for `correct`, `no_memory`, `zero`, `random`, and `wrong` payload transformations.
- `correct_repeat` is an identical repeat of `correct`; `native` is diagnostic and excluded from the primary estimand.
- The future target is an independent frozen video. It is never generated by one of the evaluated arms.
- All confirmatory arms share the exact target latent, noise, noisy latent, timestep, prompt, references, and prefix snapshot.
- Static writers are reported as `static_prefix`; only `--require-dynamic-writer` makes them fatal.
- Every machine-readable failure stays a failure and is not converted into a neutral utility value.
